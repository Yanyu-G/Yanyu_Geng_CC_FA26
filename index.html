Sandspiel

I am interested in Sandspiel, an interactive creative coding project. In Sandspiel, I can use my mouse to draw different elements, such as sand, water, fire, and plants. The elements then move and interact with each other based on the rules of the program. I like this project because I am not just drawing a static picture. My actions can create something that changes and develops over time. I think it is interesting how coding can be used to create an interactive form of art.

I think I've got the hang of these steps so far.
